# EdgeEnhance 1.1-beta1

独立 LSPosed 模块，目标为用户提供的 Microsoft Edge Android APK `152.0.4191.65`，包名 `com.microsoft.emmx`。

## 1.1-beta1 更新

- 新增前台关键事件自动复制诊断日志到剪贴板。
- 新增 `PopupWindow` 显示监控；未知弹窗记录但不关闭。
- `Dialog` 监控限定在 Edge 浏览器 Activity 内，避免记录其他应用弹窗。
- 日志缓冲上限 240 条，自动复制采用防抖，避免高频 View 事件持续覆盖剪贴板。

## 目标功能

1. **营销弹窗过滤**：尝试屏蔽默认浏览器推广、邀请好友/积分奖励和活动营销；明确保留“功能介绍 / 新功能引导”。采用弹窗文本与推广专用 View 类名的保守匹配，不会全局关闭所有 Dialog。
2. **智能返回键**：网页存在历史记录时交给 Edge 原生返回；到达历史最前端时关闭当前标签页；只剩最后一个标签页时显示退出确认框。
3. **长按底栏更多按钮**：尝试调用 Edge 自带的简易扩展面板，不打开全屏扩展管理页；普通点击不做修改。

4. **自动诊断复制**：保留最近 240 条模块日志；Edge 前台发生模块启动、弹窗发现/拦截、返回键处理、长按扩展入口或 Hook 错误等关键事件时，经过短暂防抖后自动复制诊断日志到系统剪贴板。未知 Dialog / PopupWindow 只记录、不自动拦截；功能介绍与新功能引导保留。为避免无关内容进入日志，不读取 EditText 输入内容。

## 重要状态说明

这是**实验适配版源码**，不是已通过 Edge 真机验收的正式版。用户上传的 APK 做过 DEX 字符串扫描，定位到 `ChromeTabbedActivity`、`TabModel`、`ExtensionsMenuBridge`、`ExtensionDialogManager`、`PromoDialogLayout` 等标识；但当前运行环境没有 JADX/DEX 反编译器，不能仅凭字符串确认真实方法签名。

因此：
- 返回键通过反射探测 Chromium `Tab` / `TabModel` / `WebContents` API。若当前版本的方法名或参数不匹配，会记录日志并让 Edge 执行原生行为，不会强行结束进程。
- 长按扩展面板的入口仍需真机日志验证。模块只尝试调用候选的原生面板入口；未解析成功时不会跳转到全屏管理页，也不会吞掉长按。
- 弹窗规则基于界面文字启发式匹配。若某个推广弹窗没有匹配关键词，需要根据日志补充；功能介绍类文案会优先保留。

## 构建 APK

GitHub Actions 已配置：

1. 新建 GitHub 仓库 `EdgeEnhance`。
2. 上传本项目全部文件到仓库根目录。
3. 推送到 `main` 分支，或在 Actions 页面手动运行 `Build EdgeEnhance`。
4. 下载名为 `EdgeEnhance` 的 Artifact，里面是 `EdgeEnhance.apk`。

本地构建命令：

```bash
gradle assembleDebug
```

## 安装与启用

1. 安装 `EdgeEnhance.apk`。
2. 在 LSPosed 中启用模块，并将作用域勾选为 Microsoft Edge（`com.microsoft.emmx`）。
3. 强制停止 Edge 后重新打开。
4. 模块关键事件发生后，诊断日志会自动复制到系统剪贴板；可直接在聊天输入框长按粘贴。也可以继续使用 `LSPosed → 日志` 查看以 `[EdgeEnhance]` 开头的记录。

### 自动复制说明

- 自动复制仅在 Edge 处于前台时尝试，符合 Android 对剪贴板后台访问的限制。
- 只在关键诊断事件时复制，不会对每条普通 View 日志都刷新剪贴板。
- 自动复制会覆盖当前剪贴板内容；如果你正在复制网页文字，可能被诊断日志替换。
- 最近 240 条日志保存在模块进程内存中；Edge 进程重启后会重新开始记录。
- 未知弹窗仅记录类名和可见文本摘要，不会直接关闭；已识别的营销关键词才尝试屏蔽。

## 首轮测试建议

- 打开一个有多级网页历史的标签页，按返回键确认先逐页返回。
- 到达历史最前端后按返回键，确认关闭当前标签页。
- 只剩一个标签页时按返回键，分别测试“取消”和“退出”。
- 点击更多按钮确认原菜单不变；长按更多按钮测试简易扩展面板。
- 观察默认浏览器/邀请积分营销是否被屏蔽，同时确认功能介绍/新功能引导仍显示；出现未知弹窗后，将剪贴板中的 `[EdgeEnhance]` 日志发回分析。

若某项没有生效，请导出 LSPosed 日志中 `[EdgeEnhance]` 部分；需要据实际运行类名和方法签名做第二轮定点适配。
